# Goal Space — Модульный трекер целей в стиле скандинавского минимализма

Интерактивное мобильное веб-приложение (PWA) для визуализации и структурирования долгосрочных и ежедневных целей с фокусом на измеримый результат.

## Философия интерфейса и визуальный стиль

В основе проекта лежит концепция современного скандинавского минимализма. Интерфейс избавлен от визуального шума и декоративных элементов, чтобы пользователь мог полностью сконцентрироваться на прогрессе.

Архитектура палитры построена на глубоком и спокойном тёмно-синем фоне карточек (`#3a4a75`), который создает ощущение стабильности и технологичности, в сочетании с мягким, пастельным персиково-розовым оттенком (`#f0b2b2`) для ключевых акцентов и отметок. Чистый белый фон самого приложения обеспечивает необходимый «воздух» и контраст, делая интерфейс собранным, легким и интуитивно понятным.

## Ключевые возможности

* **Фокусное разделение экранов (Dashboard):** Главный экран содержит лаконичный список текущих целей с быстрыми мини-счетчиками. Развернутая статистика, круговые диаграммы и управление открываются на внутреннем экране карточки, разделяя контекст просмотра и глубокого анализа.
* **Два типа фиксации результатов:**
  * *Дискретная (Календарная сетка):* Предназначена для фиксации регулярных целевых дней (например, график тренировок). Включает интерактивный календарь с возможностью перелистывания месяцев.
  * *Числовая (Накопительный счетчик):* Используется для отслеживания объемов (например, контроль выпитой воды в мл или прочитанных страниц). Календарная сетка скрывается, а прогресс обновляется через поле ввода с автоматическим суммированием значений в реальном времени.
* **Интегрированная статистика (Правило «внутреннего и внешнего»):** Внутренний блок карточки объединяет текстовый прогресс (например, «3 / 100»), круговую диаграмму выполнения и переключатели режимов отображения («Круг / Линия») в единую, плотную визуальную группу, наглядно демонстрирующую приближение к финалу.
* **Управление жестами и контекстом:** Быстрый доступ к редактированию и удалению на главном экране реализован через свайпы (жесты влево). Для глубоких настроек на внутреннем экране предусмотрено контекстное меню (`⋮`).
* **Автономность и PWA-архитектура:** Приложение полностью адаптировано под установку на экраны смартфонов (iOS/Android) как независимый сервис со специальной системной иконкой. Логика хранения данных реализована локально через `IndexedDB`, гарантируя сохранность пользовательского прогресса без необходимости постоянного подключения к сети.
